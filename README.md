# 新疆自由拼盘

面向 2026 年 9 月新疆自驾的手机优先路线编辑器。用户可自由选择进出机场，
按顺序加入地点，调整游玩天数与住宿夜数，并比较同地/异地还车的路线代价。

编辑器会实时计算规划里程、纯驾驶时间、含休息/吃饭/景交的现实转场、
换宿次数与缓冲，并自动生成 Day 1—Day N。所有航班、导航、租车与景区动态
信息都明确标为待核验，原型未接入实时接口。

## 本地运行

```bash
npm install
npm run dev
```

生产验证：

```bash
npm test
```

## 数据边界

- 路段数据混合使用既有资料估算与坐标道路系数粗估。
- 航班班次、票价、异地还车库存/费用不在前端伪造。
- 本地方案仅保存在浏览器 localStorage。
- 代表图用于地点辨识，并在界面中标注来源，不代表 2026 年 9 月实况。
