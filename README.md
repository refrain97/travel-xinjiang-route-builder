# 新疆自由拼盘

面向 2026 年 9 月新疆自驾的手机优先路线编辑器。用户可自由选择进出机场，
按顺序加入地点，调整游玩天数与住宿夜数，并比较同地/异地还车的路线代价。

编辑器会计算规划里程、纯驾驶时间、含休息/吃饭/景交的现实转场、
换宿次数与缓冲，并自动生成 Day 1—Day N。地图使用真实经纬度与等比例底图，
按当前地点顺序请求公路线路；航班、实时路况、租车与景区动态仍明确标为待核验。

## 本地运行

```bash
npm install
npm run dev
```

GitHub Pages 静态版：

```bash
npm run build:pages
```

生产验证：

```bash
npm test
```

## 数据边界

- 地点坐标采用城市中心或可自驾抵达的景区游客中心/入口，不把湖心、草原内部
  或区间车终点误当作自驾导航终点。
- 道路底图来自 OpenStreetMap，公路线路与模型驾时来自 OSRM；两者均不提供
  中国境内实时交通、临时封路或当日景区通行规则。
- 线路服务不可用时，地图会退回虚线联络，同时保留既有资料估算，不伪装成导航结果。
- 航班班次、票价、异地还车库存/费用不在前端伪造。
- 本地方案仅保存在浏览器 localStorage。
- 代表图用于地点辨识，并在界面中标注来源，不代表 2026 年 9 月实况。

地图数据 © OpenStreetMap contributors，依据 ODbL 使用并在地图内持续显示署名。
